# AirMind - Autonomous Edition

Este proyecto utiliza React, TypeScript, Vite y Tailwind CSS.

## 🚀 Cómo empezar (si acabas de clonar el repositorio)

Por defecto, Git no descarga la carpeta `node_modules` (ya que es muy pesada). Por lo tanto, **siempre que clones el proyecto en una computadora nueva**, debes seguir estos pasos:

### Opción 1: Automática (Windows)
1. Haz doble clic en el archivo `start.bat` que se encuentra en la raíz del proyecto.
2. Este script instalará automáticamente todas las dependencias y abrirá el servidor local.

### Opción 2: Manual (Terminal)
1. Abre tu terminal en la carpeta del proyecto.
2. Instala las dependencias ejecutando:
   ```bash
   pnpm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   pnpm run dev
   ```

## Notas adicionales
- Asegúrate de tener instalado [Node.js](https://nodejs.org/) y `pnpm` (`npm install -g pnpm`).
